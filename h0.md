# H0 - Compile and Analyze

## a)

- Ensin tein **C++** kielellä simppelin Hello World ohjelman

```c++
// hello.cpp

#include <iostream>

int main() {
    std::cout << "Hello World!";
    return 0;
}
```

- Tarkistin, että ohjelma toimii ajamalla sen

```bash
$ ./hello
Hello World!
```

- Sitten käänsin ohjelman ja tulostin sen binäärin tiedostoon nimeltä **hellobinary** ja kokeilin, että se vielä antaa oikean tulostuksen

```bash
$ g++ hello.cpp -o hellobinary
$ ./hellobinary
Hello World!
```

- Seuraavaksi tarkastelin **hellobinary** tiedostoa cat komennolla, mutta tulostus oli muodossa, jota on vaikea tutkia
